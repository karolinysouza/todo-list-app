# To-Do List

Projeto desenvolvido com **HTML**, **CSS** e **JavaScript puro**, com o objetivo de praticar manipulação do **DOM**, uso de **localStorage** e criação de uma interface intuitiva e responsiva para gerenciamento de tarefas.

O usuário pode adicionar, marcar como concluídas e remover tarefas, mantendo os dados armazenados mesmo após atualizar a página.

✨ [Acesse o site publicado](https://karolinysouza.github.io/todo-list-app/)

✨ [Veja a publicação no LinkedIn](https://www.linkedin.com/feed/update/urn:li:activity:7388692043113525248/)

---

## Tecnologias Utilizadas

* HTML5: Estrutura semântica e organizada
* CSS3: Estilização e responsividade
* JavaScript (ES6): Lógica e interatividade
* [tsparticles/confetti](https://github.com/matteobruni/tsparticles): Biblioteca para efeito de confete

---

## Funcionalidades

* Adicionar novas tarefas
* Editar o texto de uma tarefa
* Marcar tarefas como concluídas
* Excluir tarefas
* Armazenar tarefas no localStorage (persistência ao recarregar a página)
* Exibir progresso de conclusão com barra dinâmica
* Efeito de confete ao concluir todas as tarefas (usando `tsparticles.confetti`)

---

## Conceitos Praticados

* Manipulação de elementos no DOM
* Eventos (`click`, `change`, `submit`)
* Funções puras e reutilizáveis
* Atualização dinâmica de estado na tela
* Organização de código limpo e semântico
* Boas práticas de CSS responsivo
* Persistência de dados com localStorage

---

## Estilo e Design

A interface foi pensada para ser moderna, acessível e agradável, com foco na experiência do usuário:

* Paleta de cores em tons de roxo e rosa
* Layout escuro para destacar o conteúdo
* Bordas arredondadas e sombras suaves
* Transições sutis para fluidez na navegação
* Responsividade com media queries para adaptação em telas menores

<a id="english">## English (EN)</a>

# To-Do List

Project developed using **HTML**, **CSS**, and **pure JavaScript**, with the goal of practicing **DOM manipulation**, **localStorage usage**, and building an intuitive and responsive interface for task management.

The user can add tasks, mark them as completed, and remove them, with all data persisting even after reloading the page.

✨ [Access the live site](https://karolinysouza.github.io/todo-list-app/)

✨ [Check out the LinkedIn post](https://www.linkedin.com/feed/update/urn:li:activity:7388692043113525248/)

---

## Technologies Used

* HTML5: Semantic and organized structure
* CSS3: Styling and responsiveness
* JavaScript (ES6): Logic and interactivity
* [tsparticles/confetti](https://github.com/matteobruni/tsparticles): Library used for confetti animation

---

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* Save tasks to localStorage (data persistence after reload)
* Display progress with a dynamic progress bar
* Confetti effect when all tasks are completed (using `tsparticles.confetti`)

---

## Practiced Concepts

* DOM element manipulation
* Event handling (`click`, `change`, `submit`)
* Pure and reusable functions
* Dynamic state updates on screen
* Clean and semantic code organization
* Responsive CSS best practices
* Data persistence with localStorage

---

## Style and Design

The interface was designed to be modern, accessible, and pleasant, focusing on user experience:

* Purple and pink color palette
* Dark layout to highlight content
* Rounded borders and soft shadows
* Smooth transitions for navigation fluidity
* Responsive layout with media queries for smaller screens
